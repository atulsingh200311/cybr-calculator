## 🚀 Features

- 💻 **Hacker-style terminal UI** with colored output
- 🔬 **Scientific functions** (trigonometry, logarithms, exponentials, etc.)
- 🎨 **Colored interface** for better visual feedback
- 🧮 Basic arithmetic operations (+, -, ×, ÷)
- 📐 Advanced calculations (sin, cos, tan, log, sqrt, power)

---

## 🛠️ Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Codematrics-Coding-Club-Project-Based/cybr-calculator-by-Atul-Singh.git
   cd cybr-calculator-by-Atul-Singh

1. Run the calculator
   ```bash
   python calculator.py
   ```

No external dependencies required — uses only Python standard library.
